This folder contains all the data gathered from burial ground vascular-ground flora surveys and burial ground site characteristics used for analysis, with the annotated R script to produce all analyses and respective figures.

The following gives an outline for what each excel spreadsheet contains, with further information found in a README sheet within each of the datasets. 

'first_round_data' -> species presence and percentage cover data gathered during first round field surveys, ID'd by burial ground and respective cumulative quadrat sampling point.

'second_round_data' -> same as above for the second round field surveys.

'lookup' -> list of all unique taxa identified across all burial grounds across both survey rounds, with respective native status assigned.

'vegetation_height_&_leaf_blade' -> 4 vegetation height measurements, in cm, taken in each corner of every quadrat surveyed during second round surveys only, ID'd by burial ground and cumulative quadrat number. Also contains a yes/no column for whether the tips of leaf blades were cut in each respective quadrat. 

'management_proxies_raw' -> contains the data gathered to inform the 7 management proxies with the original categories 'minimum', 'moderate', and 'maximal' assigned to each burial ground for subsequent scoring 1-3 for the ordinal proxies, containing measurements for both the first and second survey round and average score across the survey rounds where applicable. ID'd by burial ground.

'management_proxies' -> contains the final data for the 7 proxies used for PCA in R. ID'd by burial ground.

'site_level_data' -> contains burial ground site-level data gathered, including survey dates, respective Julian days, and then site level characteristics (excluding management intensity) for each burial grounds canopy percentage cover, age, size and number of habitat types.

'Pilot survey data' folder -> contains species presence and percentage cover data gathered during pilot surveys, used to construct species accumulation curves to ensure the number of quadrats proposed to be sampled was adequate for representing vascular ground-flora diversity.
